# ATTESTFLE Grammaire B1–B2 — Quiz

## Mise en ligne sur GitHub Pages
1. Décompressez ce ZIP.
2. Créez un repository GitHub et téléversez les 4 fichiers à la racine.
3. Repository Settings → Pages → Build and deployment → Deploy from a branch.
4. Choisissez `main` et `/ (root)`, puis Save.

Le quiz contient 31 questions, mélangées aléatoirement, options mélangées, saisie du nom, timer (30/45/60 min), navigation, score et correction.
